# app/

Interfaz web (fase 1), diseñada para ordenador y adaptable a tableta (D-007): pantalla de creación, mapa
topográfico con símbolos APP-6 (librería milsymbol, licencia MIT), órdenes, panel de parámetros y AAR.

Hecho (fase 1, entrega 1): `terreno/` es la página de prueba del terreno y la línea de vista. Se empaqueta en un
solo HTML con `npm run build`.
